# VizualX — On-Device ML Models

This directory holds local machine learning models (TFLite, MediaPipe tasks, LiteRT models) discovered and evaluated during feasibility spikes.

## Planned Model Integrations
1. **Object Detection**: Fast mobile models (e.g. EfficientDet-Lite, MobileNet SSD) for detecting people, vehicles, doors, stairs, crosswalks.
2. **Audio Classification**: YAMNet / Sound classification model for classifying sirens, horns, approaching engines, alarms, footsteps.
3. **OCR / Text Recognition**: ML Kit Text Recognition for reading campus signs and building plaques.
4. **On-Device LLM**: Gemini Nano / AICore (where supported on hardware) or cloud fallback.
